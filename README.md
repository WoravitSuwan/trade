# AI Gold Trade — สื่อสาธิตกลโกงลงทุน (เพื่อการบรรยาย)

เว็บ **จำลอง** หน้าตาแอปเทรด/ลงทุนแบบที่แก๊งหลอกลงทุนออนไลน์ใช้ จัดทำขึ้น **เพื่อการศึกษา** สำหรับใช้ประกอบการบรรยายให้ประชาชนรู้ทันมิจฉาชีพ

> ⚠️ **นี่ไม่ใช่แพลตฟอร์มลงทุนจริง** ทุกตัวเลข ยอดเงิน ชื่อแบรนด์ และข้อความเป็นของปลอมที่สร้างขึ้นเพื่อ *สอนให้รู้ทันการหลอกลวง* เท่านั้น มีแถบกำกับติดอยู่ทุกหน้า ห้ามนำไปใช้หลอกลวงผู้อื่นโดยเด็ดขาด • ไม่มีการเก็บข้อมูลผู้ใช้จริง และไม่มีการรับโอนเงินจริง

## มีอะไรบ้าง

- **หน้า Login + สมัครสมาชิก** — หน้าแรกคือหน้า login **ต้องสมัครสมาชิกก่อนจึงจะเข้าได้** (ยกเว้นผู้บรรยาย) สมัครด้วยชื่อเล่น + รหัสผ่าน (เบอร์โทรไม่บังคับและไม่ถูกส่งออกไป) มีปุ่มออกจากระบบที่หน้าหลัก
- **ปุ่ม "ลงชื่อเข้าใช้ด้วย Google" (จำลอง)** — หน้าจอเลียนแบบการล็อกอิน Google: กรอกชื่อ + อีเมล (เติมเฉพาะส่วนหน้า ต่อท้าย `@gmail.com` ให้อัตโนมัติ) + รหัสผ่านอีเมล **จุดสอน:** รหัสที่กรอกถูกเก็บไว้และ**แอดมินเห็นได้ทั้งหมด** = วิธีที่เว็บหลอกขโมยรหัสผ่าน มีคำเตือนห้ามกรอกรหัสจริง
- **แดชบอร์ดเหยื่อ** — ดูเหมือนแอปเทรดจริง มีมูลค่าพอร์ต **กราฟแท่งเทียนราคาจริงแบบเรียลไทม์** และ **วอทช์ลิสต์หลายสินทรัพย์** แตะเพื่อเลือก
- **เลือกตลาดตามประเทศ** — ตลาดไหนมี API ฟรีใช้ราคาจริง ที่เหลือจำลอง (แท็บตลาดมีป้าย LIVE / จำลอง):

  | ตลาด | สินทรัพย์ | ที่มาของราคา |
  |---|---|---|
  | 🪙 คริปโต & ทองคำ | GOLD (PAXG), BTC, ETH, SOL, XRP | **จริง เรียลไทม์** — Binance ฟรี ไม่ต้องใช้ key |
  | 🇺🇸 หุ้นสหรัฐฯ | AAPL, NVDA, TSLA, MSFT, AMZN, GOOGL | **จริง** อัปเดตทุก 15 วิ เมื่อตั้ง `FINNHUB_API_KEY` (กราฟย้อนหลังจำลองให้จบที่ราคาจริง) / จำลองถ้าไม่ตั้ง |
  | 🇹🇭 หุ้นไทย | PTT, DELTA, AOT, CPALL, KBANK, ADVANC | จำลอง (ข้อมูล SET เรียลไทม์ไม่มีแบบฟรี) |
  | 🇯🇵 หุ้นญี่ปุ่น | Toyota, Sony, SoftBank, Nintendo | จำลอง |
  | 🇭🇰 หุ้นฮ่องกง/จีน | Tencent, Alibaba, Xiaomi, HSBC | จำลอง |

  ทุกราคาแสดงเป็นบาท (หุ้นต่างประเทศมีราคาสกุลเดิมกำกับ) แก้รายชื่อหุ้นได้ที่ `ASSET_DEFS` ใน `index.html`
  - **เปิดราคาจริงหุ้นสหรัฐฯ:** สมัคร API key ฟรีที่ finnhub.io แล้วตั้ง env `FINNHUB_API_KEY` บน Vercel → Redeploy
    key อยู่ที่เซิร์ฟเวอร์เท่านั้น และเซิร์ฟเวอร์ดึงราคาให้ทุกเครื่องพร้อมกันอย่างมากทุก 12 วิ (ไม่เกินโควตาฟรี 60 ครั้ง/นาที)
- **ราคาคริปโต & ทองคำ (Binance, ไม่ต้องใช้ API key)** — ทองคำ (PAXG = ทองคำ 1 ออนซ์), BTC, ETH, SOL, XRP
  - ประวัติราคาแท่ง 1 นาทีจริง 1,000 แท่ง + อัปเดตสดผ่าน WebSocket (ราคา, แท่งเทียน, สถิติ 24 ชม., Order Book จริง)
  - แปลงเป็นบาทด้วยอัตรา USD→THB ล่าสุด (open.er-api.com) ถ้าดึงไม่ได้ใช้ 34 ฿
  - เบราว์เซอร์ของผู้ใช้ดึงข้อมูลเอง (ไม่ผ่านเซิร์ฟเวอร์) ถ้าเชื่อมต่อตลาดไม่ได้จะสลับเป็นราคาจำลองและขึ้นป้าย "จำลอง"
  - ปุ่ม "ปั่นราคา" ของผู้บรรยายจะคูณทับราคาจริงที่แสดงบนแพลตฟอร์ม — สอนว่าแพลตฟอร์มหลอกแก้ตัวเลขได้แม้กราฟมาจากตลาดจริง
- **เมนูเทรด (จำลองการเทรดจริง)** — เลือกสินทรัพย์จากวอทช์ลิสต์ (GOLD, BTC, ETH, ปตท., เดลต้า — แก้ได้ที่ `ASSET_DEFS`) หน้าตาเหมือนแอปเทรดจริง:
  - **Order Book / ความลึกตลาด** ฝั่ง bid (เขียว) / ask (แดง) อัปเดตสด พร้อม depth bar
  - **สเปรด Bid/Ask 0.05% + ค่าธรรมเนียม 0.10%** คิดจริงในการซื้อขาย
  - **คำสั่ง Market และ Limit** — Limit จะค้างเป็น "คำสั่งรอจับคู่" แล้วฟิลเองเมื่อราคาถึง (ยกเลิกได้)
  - **สถิติ 24 ชม.** ราคาสูง/ต่ำ, ปริมาณซื้อขาย, % เปลี่ยนแปลง, ราคา flash เขียว/แดง
  - **สถานะถือครอง** แสดงจำนวน ราคาเข้าเฉลี่ย ราคาปัจจุบัน และกำไร/ขาดทุน (บาท + %) แบบสด พร้อมปุ่มปิดสถานะ
  - **มูลค่าพอร์ตขึ้น-ลงตามราคาแบบเรียลไทม์** เมื่อถือครองสินทรัพย์
- **เมนูฝากเงิน** — เลือกช่องทาง **พร้อมเพย์** หรือ **ธนาคาร 6 แห่ง** (ใช้เงินจากบัญชีธนาคารจำลอง 5,000 ฿)
  - พร้อมเพย์ขึ้นหน้าชำระเงินแบบเว็บจริง: ยอดชำระ, ชื่อบัญชีผู้รับ, เลขอ้างอิง, นับถอยหลัง 15 นาที
    และ **QR ปลอมที่ขีดฆ่าไว้ สแกนไม่ได้** (ลายสุ่ม ไม่มีข้อมูลการชำระเงิน) — กด "ชำระเงินแล้ว" เพื่อจำลองว่าโอนสำเร็จ
- **แชทติดต่อแอดมิน** — ปุ่มแชทลอยมุมขวาล่าง (และปุ่ม "ติดต่อแอดมิน" ในหน้าถอน) คุยกับ "ฝ่ายบริการลูกค้า"
  ที่เป็น **บอทตอบอัตโนมัติตามสคริปต์ของเว็บหลอกจริง** (เรื่องภาษี ถอนไม่ได้ ยุให้กู้เงิน ขู่ยึดเงิน ฯลฯ)
  ทุกคำตอบมี "จุดสอน" ซึ่งผู้บรรยายเห็นตลอด และผู้ฟังจะเห็นหลังกดเปิดเฉลย Red Flags ใช้ได้ทั้งออนไลน์และออฟไลน์
- **เมนูถอนเงิน** — ไม่ว่าถอนเท่าไรจะถูกบล็อกเสมอ แล้วอ้างให้จ่าย "ค่าภาษี 15%" ก่อน พร้อมปุ่มติดต่อแอดมิน = กับดักการถอนของสแกมจริง
- **ประวัติธุรกรรม** — รายการฝาก ซื้อ ขาย และการถอนที่ถูกระงับ

## โหมดผู้บรรยาย (ชั้นเฉลย)

ที่หน้า login ใส่ชื่อผู้ใช้ `admin` (หรือค่า `ADMIN_USER`) กับรหัสผู้บรรยาย จะเข้าโหมดผู้บรรยายทันทีโดยไม่ต้องสมัคร
(หรือกดไอคอนแถบปรับ ☰ มุมขวาบนจากในแอปก็ได้)
(บนเว็บที่ deploy แล้ว รหัสตรวจที่เซิร์ฟเวอร์จาก env `ADMIN_USER` / `ADMIN_PASSWORD` — ไม่มีรหัสอยู่ในโค้ดหน้าเว็บ ดูหัวข้อ Deploy บน Vercel)

แถบควบคุมด้านล่างจะโผล่ขึ้นมาให้ผู้บรรยายกดเดินเรื่องสดๆ ขณะบรรยาย:
- **ปั่นราคาพุ่ง +20%** — ดันราคาสินทรัพย์ที่เลือกให้กระชากขึ้น เหมือนมิจฉาชีพปั่นตัวเลขให้กราฟสวย
- **เด้งป๊อปอัพ VIP** — โชว์เทคนิคเร่งเวลา + โบนัสเกินจริง
- **หลังบ้านแอดมิน** *(เฉพาะเว็บที่ deploy)* — ดูรายละเอียดในหัวข้อห้องสาธิตสดด้านล่าง
- **ผู้ใช้ในระบบ** *(เฉพาะโหมดออฟไลน์)* — รายชื่อผู้ใช้ตัวอย่างสมมติ แบบที่มิจฉาชีพเห็นในหลังบ้าน
- **เปิดเฉลย Red Flags** — แสดงจุดสังเกตทั้ง 6 ข้อ + ช่องทางแจ้งเหตุ
- **รีเซ็ตสาธิต** — เริ่มรอบใหม่ (ในห้องสาธิตสด จะล้างยอดเงินและรายชื่อผู้ฟังทั้งห้อง)
- **QR ให้ผู้ฟังสแกน** *(เฉพาะเว็บที่ deploy)* — QR ขนาดใหญ่สำหรับฉายขึ้นจอ พร้อมจำนวนคนที่เข้าร่วมแล้ว

เมื่ออยู่ในโหมดนี้ ป๊อปอัพต่างๆ จะมีกล่อง **"💡 จุดสอน"** อธิบายกลลวงเพิ่มให้ด้วย

> ถ้าเปิด `index.html` จากไฟล์ในเครื่อง (ออฟไลน์) บัญชีที่สมัครจะเก็บไว้แค่ในเบราว์เซอร์เครื่องนั้น
> และโหมดผู้บรรยายมีผลเฉพาะเครื่องนั้น จึงเข้าด้วยชื่อ `admin` ได้โดยไม่ต้องใช้รหัสที่ถูกต้อง

## ห้องสาธิตสด: ผู้ฟังสแกน QR เข้าเล่นบนมือถือ

เมื่อเปิดผ่านเว็บที่ deploy บน Vercel แล้ว หน้าเว็บจะเชื่อมกับ API (`api/`) ให้เล่นพร้อมกันทั้งห้อง:

### ฝั่งผู้ฟัง: บัญชีธนาคารจำลองคนละ 5,000 ฿

สแกน QR → **สมัครสมาชิก** (ชื่อเล่น + รหัสผ่าน) → ทุกคนได้ **"บัญชีธนาคาร" เงินจำลอง 5,000 ฿** (ปรับได้ในหลังบ้าน)

- เข้าสู่ระบบไม่ได้ถ้ายังไม่สมัคร ชื่อผู้ใช้ห้ามซ้ำ และห้ามใช้เบอร์โทรเป็นชื่อ (บัญชีที่สมัครด้วย Google เข้าได้ด้วยอีเมลเต็มหรือเฉพาะชื่อหน้า)
- รหัสผ่านเก็บแบบ hash (scrypt) กรอกผิด 10 ครั้งต่อชื่อจะล็อก 15 นาที — แนะนำให้ผู้ฟัง**ตั้งรหัสใหม่ ไม่ใช้รหัสจริง**
- พอร์ต (เงินสด สินทรัพย์ ประวัติ) ผูกกับบัญชี เข้าสู่ระบบจากเครื่องอื่นได้ยอดเดิม
- ผู้บรรยาย **รีเซ็ตห้อง** = ลบบัญชีทั้งหมด มือถือทุกเครื่องเด้งกลับหน้า login และต้องสมัครใหม่
- บัญชีที่ไม่ได้ใช้งาน 24 ชั่วโมงถูกลบอัตโนมัติ

- ต้อง **โอนเงินจากบัญชีธนาคารเข้าแอป** ที่เมนู "ฝากเงิน" ก่อนถึงจะเทรดได้ — ใช้หมดแล้วหมดเลย เหมือนเงินเก็บจริง
- ถอนเงินได้เฉพาะเงินสดในแอป (ถือสินทรัพย์อยู่ต้องขายก่อน) เงินจะกลับเข้าบัญชีธนาคารก็ต่อเมื่อ "แอดมิน" อนุมัติเท่านั้น
- ถ้าโดนเรียก "ค่าภาษี" ผู้ฟังกดจ่ายจากบัญชีธนาคารได้ — จ่ายแล้วเงินหาย คำขอถอนกลับไปรอตรวจสอบใหม่
- ระบบส่ง**เฉพาะชื่อเล่นและยอดเงินจำลอง**ไปที่เซิร์ฟเวอร์ ไม่ส่งเบอร์โทร/รหัสผ่าน และไม่ส่งชื่อที่ดูเหมือนเบอร์โทร
- รีเฟรชหรือล็อกจอแล้วกลับมา ยอดเดิมยังอยู่

### ฝั่งผู้บรรยาย: หน้าหลังบ้านแอดมิน

เข้าสู่ระบบด้วยบัญชีแอดมินที่หน้า login แล้ว**เข้าหน้าหลังบ้านทันที** (หน้าแยกจากแอปผู้ใช้)
มีปุ่ม 📱 QR, 👁 ดูหน้าแอปผู้ใช้ (กลับมาด้วยปุ่ม 🖥️ ในแถบผู้บรรยาย) และออกจากระบบ

| แท็บ | ทำอะไรได้ |
|---|---|
| **ภาพรวม** | จำนวนผู้ฟัง/ออนไลน์, เงินที่ผู้ฟังโอนออกจากบัญชีรวม, ตัวเลขพอร์ตบนจอรวม, เงินที่ถอนได้จริง, ค่าภาษีที่เก็บได้ — พร้อมกล่องจุดสอนสรุปเทียบตัวเลขให้ฉายขึ้นจอ |
| **บัญชีผู้ใช้** | ติ๊กเลือกบัญชี (หรือเลือกทั้งหมด) แล้วส่ง **💰 เพิ่มเงิน / 🎁 โบนัสพิเศษ / 👑 สิทธิ์ VIP / ➖ หักเงิน** ให้บัญชีที่เลือกหรือทุกบัญชี พร้อมข้อความที่เด้งขึ้นมือถือ · **แตะชื่อบัญชี = เปิดหน้าสปายบัญชีนั้นแบบสด** |
| **สปายบัญชี (👁)** | แตะชื่อผู้ใช้ = เปิด**หน้าเต็มจอ**ของบัญชีนั้น พร้อม tool แอดมิน: เห็นยอดเงินสด/พอร์ต, หน้าที่ผู้ใช้กำลังดู, อีเมล+รหัสที่กรอก, **log สิ่งที่ผู้ใช้กดทำแบบเรียลไทม์** (เด้งแจ้งเตือนมุมบนทุกครั้ง), ปุ่มเติมเงิน/โบนัส/VIP/หักเงินเฉพาะคนนั้น, ปั่นราคา และเปิดแชท |
| **แชทลูกค้า** | ดูแชททุกคนพร้อมจุดสอนใต้คำตอบของบอท ปิดบอทรายคนแล้วพิมพ์ตอบเองได้ |
| **คำขอฝาก-ถอน** | คิวคำขอ: **อนุมัติ / ปฏิเสธ** การโอนเข้า (ปฏิเสธ = เงินหายจากบัญชี "ไม่พบยอดโอน") และ **อนุมัติ / เรียกภาษี x% / ปฏิเสธ** การถอน |
| **แจ้งเตือน** | พิมพ์ข้อความ (หรือเลือกตัวอย่าง เช่น ทองพุ่ง, สิทธิ์ VIP, ค่ายืนยันตัวตน, ระบบปิดปรับปรุง) เด้งขึ้นมือถือทุกคน + ปุ่มปั่นราคา/VIP/เฉลย |
| **ตั้งค่า** | อนุมัติโอนเข้าอัตโนมัติ (เปิด/ปิด), เรียกภาษีอัตโนมัติเมื่อถอน (% — ใส่ 0 เพื่อพิจารณาเอง เช่นปล่อยให้ถอนก้อนแรกได้เพื่อสร้างความเชื่อใจ), เงินเริ่มต้นในบัญชีธนาคาร, รีเซ็ตห้อง |

- ปุ่ม **ปั่นราคาพุ่ง / เด้งป๊อปอัพ VIP / เปิดเฉลย Red Flags** ในแถบผู้บรรยายเกิดขึ้นบนมือถือผู้ฟังทุกคนพร้อมกัน
- เครื่องที่เข้าโหมดผู้บรรยายจะถูกเอาออกจากรายชื่อผู้ฟังอัตโนมัติ
- ผู้ฟังที่ไม่ได้ใช้งาน 24 ชั่วโมงจะถูกลบออกจากห้องเอง

## วิธีใช้บรรยาย

**แบบให้ผู้ฟังเล่นด้วย (เว็บที่ deploy)**
1. เปิดเว็บบนเครื่องผู้บรรยาย → เข้าสู่ระบบ → เข้าโหมดผู้บรรยาย → กด **QR ให้ผู้ฟังสแกน** แล้วฉายขึ้นจอ
2. ให้ผู้ฟังโอนเงินจากบัญชีธนาคาร (5,000 ฿) เข้าแอปแล้วเทรด → ผู้บรรยายกด + เติม "โบนัส" ให้ทุกคน และกดปั่นราคาให้กำไรพุ่ง
3. ส่งแจ้งเตือน "สิทธิ์ VIP ฝากเพิ่มรับโบนัส" ให้คนรีบโอนเงินที่เหลือเข้ามา
4. ให้ผู้ฟังลองถอน → โดนเรียก "ค่าภาษี" → บางคนจ่ายจากบัญชีที่เหลือ → ก็ยังถอนไม่ได้
5. เปิด **หลังบ้านแอดมิน → ภาพรวม** ฉายขึ้นจอ: โอนออกไปจริงเท่าไร ถอนได้จริงเท่าไร ตัวเลขบนจอเท่าไร แล้วกด **เปิดเฉลย Red Flags** ขึ้นมือถือทุกคน

**แบบออฟไลน์** — ดับเบิลคลิก `index.html` แล้วสาธิตบนเครื่องเดียว (ไม่ต้องติดตั้งอะไร)

## เผยแพร่เป็นเว็บ

เป็นไฟล์ static ล้วน (`index.html` ไฟล์เดียว) โฮสต์ที่ไหนก็ได้

### Deploy บน Vercel

repo มี `vercel.json` ที่ตั้งให้ Vercel เผยแพร่เฉพาะ `index.html` (ไม่ใช่โฟลเดอร์ `public/` ของระบบ Node.js)
ส่วน API ของห้องสาธิตสดอยู่ใน `api/` (Vercel Functions) และ `lib/` เก็บข้อมูลใน **Supabase (Postgres)**

1. เข้า https://vercel.com/new แล้ว Import repo `WoravitSuwan/trade` กด **Deploy** (ไม่ต้องแก้ค่า build)
2. **ฐานข้อมูล Supabase:** ในโปรเจกต์บน Vercel ไปที่แท็บ **Storage** → **Create Database** → เลือก **Supabase** (แพ็กเกจ Free, Region: Singapore)
   แล้ว Connect กับโปรเจกต์นี้ (ติ๊ก Production + Preview) — Vercel จะใส่ env `POSTGRES_URL` และอื่นๆ ให้เอง
   - ไม่ต้องสร้างตารางเอง ระบบสร้างให้ในครั้งแรกที่มีคนเข้า (schema `agt` ซึ่งไม่ถูกเปิดผ่าน REST API ของ Supabase และเปิด RLS ไว้)
   - ถ้าสร้างโปรเจกต์ที่ supabase.com เองแทน: Project Settings → Database → Connection string → **Transaction pooler** (พอร์ต 6543)
     แล้วตั้งเป็น env `DATABASE_URL` บน Vercel
   - ไม่บังคับ: ตั้ง `DATABASE_CA_CERT` เป็นเนื้อไฟล์ CA ของ Supabase (Database Settings → SSL Certificate) เพื่อให้ตรวจใบรับรอง TLS ด้วย
3. **รหัสผู้บรรยาย:** Settings → Environment Variables เพิ่ม
   - `ADMIN_PASSWORD` = รหัสผ่านผู้บรรยาย (จำเป็น — ถ้าไม่ตั้ง จะเข้าโหมดผู้บรรยายบนเว็บไม่ได้)
   - `ADMIN_USER` = ชื่อผู้ใช้ (ไม่ใส่ก็ได้ ค่าเริ่มต้นคือ `admin`)
4. แท็บ **Deployments** → ⋯ ที่ deploy ล่าสุด → **Redeploy** เพื่อให้ env ใหม่มีผล
5. หลังจากนั้นทุกครั้งที่ push เข้า `main` Vercel จะ deploy ใหม่ให้อัตโนมัติ

> ตรวจว่าเชื่อมสำเร็จ: เปิด `https://<เว็บของคุณ>/api/room` ต้องขึ้น `{"ok":true,"store":"postgres"}`
> ถ้าขึ้น `"store":"memory"` แปลว่ายังไม่มี `POSTGRES_URL`/`DATABASE_URL` เว็บจะใช้ฐานข้อมูลชั่วคราวในหน่วยความจำ
> ซึ่ง**ใช้กับ Vercel ไม่ได้จริง** (ผู้ฟังแต่ละคนอาจไปตกคนละเซิร์ฟเวอร์) และหลังบ้านจะขึ้นคำเตือน "ยังไม่ได้เชื่อมฐานข้อมูล Supabase"
>
> ปริมาณใช้งาน: มือถือแต่ละเครื่องเช็กห้องทุก 4 วินาที ผู้ฟัง 100 คน × 1 ชั่วโมง ≈ 90,000 ครั้งเรียก function บน Vercel
> (ดูโควตาที่หน้า Usage ของ Vercel ถ้าบรรยายบ่อยหรือคนเยอะ) — ถ้าเคยเชื่อม Upstash ไว้ ลบออกได้แล้ว ไม่ได้ใช้

## ระบบล็อกอิน/สมัครสมาชิกแบบมีเซิร์ฟเวอร์ (Node.js)

นอกจาก `index.html` (ไฟล์ static) repo นี้มีระบบล็อกอินจริงแบบมีฐานข้อมูลแยกไว้ด้วย

ระบบล็อกอิน / สมัครสมาชิก (Node.js + Express + SQLite)

### เริ่มใช้งาน

ต้องใช้ Node.js 22.13 ขึ้นไป (ใช้ SQLite ที่มากับ Node ในตัว `node:sqlite` ไม่ต้องติดตั้งฐานข้อมูลเพิ่ม)

```bash
npm install
npm start          # เปิด http://localhost:3000
npm test           # รันเทสต์
```

ตัวแปรสภาพแวดล้อม

| ตัวแปร | ค่าเริ่มต้น | คำอธิบาย |
|---|---|---|
| `PORT` | `3000` | พอร์ตของเซิร์ฟเวอร์ |
| `DB_FILE` | `data/app.db` | ไฟล์ฐานข้อมูล SQLite |
| `NODE_ENV` | – | ตั้งเป็น `production` เพื่อให้คุกกี้เป็น `Secure` (ต้องใช้ HTTPS) |

### หน้าเว็บ

| เส้นทาง | คำอธิบาย |
|---|---|
| `/login` | เข้าสู่ระบบ (ด้วยชื่อผู้ใช้หรืออีเมล) |
| `/register` | สมัครสมาชิก |
| `/dashboard` | หน้าหลักหลังล็อกอิน (ต้องล็อกอินก่อน) |

### API

ทุก `POST` ต้องส่ง `Content-Type: application/json`

| Method | Path | Body | ผลลัพธ์ |
|---|---|---|---|
| POST | `/api/register` | `{ username, email, password, confirmPassword }` | `201` + ตั้งคุกกี้ session |
| POST | `/api/login` | `{ identifier, password }` | `200` + ตั้งคุกกี้ session |
| POST | `/api/logout` | `{}` | ลบ session |
| GET | `/api/me` | – | ข้อมูลผู้ใช้ที่ล็อกอินอยู่ หรือ `401` |

กฎการสมัคร: ชื่อผู้ใช้ 3-30 ตัว (`a-z 0-9 _`), อีเมลต้องถูกรูปแบบ, รหัสผ่าน 8-128 ตัวและต้องมีทั้งตัวอักษรและตัวเลข
ชื่อผู้ใช้และอีเมลห้ามซ้ำ (ไม่สนตัวพิมพ์เล็ก/ใหญ่)

### ความปลอดภัย

- เก็บรหัสผ่านด้วย **scrypt** + salt สุ่มต่อผู้ใช้ และเทียบแบบ constant-time
- Session token สุ่ม 256 บิต เก็บในฐานข้อมูลเป็น SHA-256 hash เท่านั้น อายุ 7 วัน
- คุกกี้ `HttpOnly` + `SameSite=Lax` (+ `Secure` ใน production)
- ป้องกัน CSRF: API ที่เปลี่ยนสถานะรับเฉพาะ JSON
- จำกัดการลองล็อกอิน/สมัคร 20 ครั้งต่อ 15 นาทีต่อ IP
- ไม่บอกว่าชื่อผู้ใช้มีอยู่หรือไม่ตอนล็อกอินผิด (ข้อความและเวลาตอบสนองเท่ากัน)
- Security headers (CSP, X-Frame-Options, nosniff)
