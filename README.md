# AI Gold Trade — สื่อสาธิตกลโกงลงทุน (เพื่อการบรรยาย)

เว็บ **จำลอง** หน้าตาแอปเทรด/ลงทุนแบบที่แก๊งหลอกลงทุนออนไลน์ใช้ จัดทำขึ้น **เพื่อการศึกษา** สำหรับใช้ประกอบการบรรยายให้ประชาชนรู้ทันมิจฉาชีพ

> ⚠️ **นี่ไม่ใช่แพลตฟอร์มลงทุนจริง** ทุกตัวเลข ยอดเงิน ชื่อแบรนด์ และข้อความเป็นของปลอมที่สร้างขึ้นเพื่อ *สอนให้รู้ทันการหลอกลวง* เท่านั้น มีแถบกำกับติดอยู่ทุกหน้า ห้ามนำไปใช้หลอกลวงผู้อื่นโดยเด็ดขาด • ไม่มีการเก็บข้อมูลผู้ใช้จริง และไม่มีการรับโอนเงินจริง

## มีอะไรบ้าง

- **หน้า Login + สมัครสมาชิก** — หน้าสมัครให้กรอกชื่อ/เบอร์/รหัส (เป็นฉากประกอบ ข้อมูลอยู่แค่ในเครื่องชั่วคราว ไม่บันทึก/ไม่ส่งออกไปไหน) แดชบอร์ดจะทักทายตามชื่อที่กรอก
- **แดชบอร์ดเหยื่อ** — ดูเหมือนแอปเทรดจริง มีมูลค่าพอร์ต **กราฟแท่งเทียน (candlestick) เรียลไทม์** ที่ราคาวิ่งขึ้น-ลงทุกวินาที (แท่งเขียว/แดง + ราคา LIVE) ข้อมูลมาจาก API จำลอง ไม่ได้ต่อตลาดจริง พร้อม **วอทช์ลิสต์หลายสินทรัพย์** แตะเพื่อเลือก
- **เมนูเทรด (จำลองการเทรดจริง)** — เลือกสินทรัพย์จากวอทช์ลิสต์ (GOLD, BTC, ETH, ปตท., เดลต้า — แก้ได้ที่ `ASSET_DEFS`) หน้าตาเหมือนแอปเทรดจริง:
  - **Order Book / ความลึกตลาด** ฝั่ง bid (เขียว) / ask (แดง) อัปเดตสด พร้อม depth bar
  - **สเปรด Bid/Ask 0.05% + ค่าธรรมเนียม 0.10%** คิดจริงในการซื้อขาย
  - **คำสั่ง Market และ Limit** — Limit จะค้างเป็น "คำสั่งรอจับคู่" แล้วฟิลเองเมื่อราคาถึง (ยกเลิกได้)
  - **สถิติ 24 ชม.** ราคาสูง/ต่ำ, ปริมาณซื้อขาย, % เปลี่ยนแปลง, ราคา flash เขียว/แดง
  - **สถานะถือครอง** แสดงจำนวน ราคาเข้าเฉลี่ย ราคาปัจจุบัน และกำไร/ขาดทุน (บาท + %) แบบสด พร้อมปุ่มปิดสถานะ
  - **มูลค่าพอร์ตขึ้น-ลงตามราคาแบบเรียลไทม์** เมื่อถือครองสินทรัพย์
- **เมนูฝากเงิน** — เติมเงินสด (ปลอม) เพื่อใช้ซื้อขาย เลียนแบบวิธีให้เหยื่อเติมเงินเข้าระบบ
- **เมนูถอนเงิน** — ไม่ว่าถอนเท่าไรจะถูกบล็อกเสมอ แล้วอ้างให้จ่าย "ค่าภาษี 15%" ก่อน พร้อมปุ่มติดต่อแอดมิน = กับดักการถอนของสแกมจริง
- **ประวัติธุรกรรม** — รายการฝาก ซื้อ ขาย และการถอนที่ถูกระงับ

## โหมดผู้บรรยาย (ชั้นเฉลย)

กดไอคอนแถบปรับ (☰ แนวตั้ง) มุมขวาบนข้างยอดคงเหลือ → เข้าด้วย **admin / 1234**

แถบควบคุมด้านล่างจะโผล่ขึ้นมาให้ผู้บรรยายกดเดินเรื่องสดๆ ขณะบรรยาย:
- **ปั่นราคาพุ่ง +20%** — ดันราคาสินทรัพย์ที่เลือกให้กระชากขึ้น เหมือนมิจฉาชีพปั่นตัวเลขให้กราฟสวย
- **เด้งป๊อปอัพ VIP** — โชว์เทคนิคเร่งเวลา + โบนัสเกินจริง
- **ผู้ใช้ในระบบ** — ดูรายชื่อผู้ใช้ (ชื่อ/เบอร์/ยอดเงิน/การลงทุน) แบบที่มิจฉาชีพเห็นในหลังบ้าน มีผู้ใช้ปัจจุบัน + เหยื่อตัวอย่างสมมติ
- **เปิดเฉลย Red Flags** — แสดงจุดสังเกตทั้ง 6 ข้อ + ช่องทางแจ้งเหตุ
- **รีเซ็ตสาธิต** — เริ่มรอบใหม่

เมื่ออยู่ในโหมดนี้ ป๊อปอัพต่างๆ จะมีกล่อง **"💡 จุดสอน"** อธิบายกลลวงเพิ่มให้ด้วย

> หมายเหตุ: admin/1234 เป็นเพียงรหัสสาธิตแบบ hardcode ฝั่งหน้าเว็บ ไม่ใช่ระบบหลังบ้านหรือระบบรักษาความปลอดภัยจริง ใช้สลับเข้า "โหมดผู้บรรยาย" เท่านั้น

## วิธีใช้บรรยาย

1. เปิด `index.html` ด้วยเบราว์เซอร์ (ดับเบิลคลิกได้เลย ไม่ต้องติดตั้งอะไร ใช้ออฟไลน์ได้)
2. ฉายขึ้นจอ เริ่มที่หน้า login แล้ว "เข้าสู่ระบบ"
3. สาธิตให้ผู้ฟังดู: ฝากเงิน → เห็นกำไรพุ่ง → ลองถอน → โดนบล็อก
4. สลับเข้าโหมดผู้บรรยาย (admin/1234) เพื่อปั่นยอดสดและเปิดเฉลย red flags ให้ผู้ฟัง "จับไต๋ได้"

## ระบบล็อกอิน/สมัครสมาชิกแบบมีเซิร์ฟเวอร์ (Node.js)

นอกจาก `index.html` (ไฟล์ static) repo นี้มีระบบล็อกอินจริงแบบมีฐานข้อมูลแยกไว้ด้วย

ระบบล็อกอิน / สมัครสมาชิก (Node.js + Express + SQLite)

### เริ่มใช้งาน

ต้องใช้ Node.js 22.13 ขึ้นไป (ใช้ SQLite ที่มากับ Node ในตัว `node:sqlite` ไม่ต้องติดตั้งฐานข้อมูลเพิ่ม)

```bash
npm install
npm start          # เปิด http://localhost:3000
npm test           # รันเทสต์
```

ตัวแปรสภาพแวดล้อม

| ตัวแปร | ค่าเริ่มต้น | คำอธิบาย |
|---|---|---|
| `PORT` | `3000` | พอร์ตของเซิร์ฟเวอร์ |
| `DB_FILE` | `data/app.db` | ไฟล์ฐานข้อมูล SQLite |
| `NODE_ENV` | – | ตั้งเป็น `production` เพื่อให้คุกกี้เป็น `Secure` (ต้องใช้ HTTPS) |

### หน้าเว็บ

| เส้นทาง | คำอธิบาย |
|---|---|
| `/login` | เข้าสู่ระบบ (ด้วยชื่อผู้ใช้หรืออีเมล) |
| `/register` | สมัครสมาชิก |
| `/dashboard` | หน้าหลักหลังล็อกอิน (ต้องล็อกอินก่อน) |

### API

ทุก `POST` ต้องส่ง `Content-Type: application/json`

| Method | Path | Body | ผลลัพธ์ |
|---|---|---|---|
| POST | `/api/register` | `{ username, email, password, confirmPassword }` | `201` + ตั้งคุกกี้ session |
| POST | `/api/login` | `{ identifier, password }` | `200` + ตั้งคุกกี้ session |
| POST | `/api/logout` | `{}` | ลบ session |
| GET | `/api/me` | – | ข้อมูลผู้ใช้ที่ล็อกอินอยู่ หรือ `401` |

กฎการสมัคร: ชื่อผู้ใช้ 3-30 ตัว (`a-z 0-9 _`), อีเมลต้องถูกรูปแบบ, รหัสผ่าน 8-128 ตัวและต้องมีทั้งตัวอักษรและตัวเลข
ชื่อผู้ใช้และอีเมลห้ามซ้ำ (ไม่สนตัวพิมพ์เล็ก/ใหญ่)

### ความปลอดภัย

- เก็บรหัสผ่านด้วย **scrypt** + salt สุ่มต่อผู้ใช้ และเทียบแบบ constant-time
- Session token สุ่ม 256 บิต เก็บในฐานข้อมูลเป็น SHA-256 hash เท่านั้น อายุ 7 วัน
- คุกกี้ `HttpOnly` + `SameSite=Lax` (+ `Secure` ใน production)
- ป้องกัน CSRF: API ที่เปลี่ยนสถานะรับเฉพาะ JSON
- จำกัดการลองล็อกอิน/สมัคร 20 ครั้งต่อ 15 นาทีต่อ IP
- ไม่บอกว่าชื่อผู้ใช้มีอยู่หรือไม่ตอนล็อกอินผิด (ข้อความและเวลาตอบสนองเท่ากัน)
- Security headers (CSP, X-Frame-Options, nosniff)
